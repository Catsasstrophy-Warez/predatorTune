# Rev155 — Synchronized Forensic Cockpit

Rev155 turns the shared cursor into a cockpit-wide read-only investigation bus. It composes existing Twin relevance, Golden Corpus A/B navigation windows, hypothesis selection, calibration research relationships, and missing discriminating measurements into one packet without promoting correlation to causality.

## Invariants
- A/B windows remain observed navigation windows with derived/noncausal comparison semantics.
- Twin highlighting means relevance, not health/failure.
- Calibration links remain RESEARCH RELATIONSHIP until controller/OS-specific evidence exists.
- Best Next Measurement prioritizes missing evidence; it is not a diagnosis.
- DCT context never labels input/output RPM difference as clutch slip without verified shaft/gear/clutch semantics.
